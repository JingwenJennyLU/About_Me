# Data Science & Computational Social Science Portfolio
**Jingwen LU** *M.A. Candidate in Computational Social Science at the University of Chicago*

Welcome to my Python project portfolio! This repository showcases my work in data management, machine learning, and applied computational social science. My projects focus on leveraging Python for data pipelines, natural language processing (NLP), social network analysis, and algorithmic problem-solving.

## 📂 Repository Structure

### 1. [Data_Management](./Python_Projects/Data_Management/)
This section contains projects focused on data extraction, transformation, and database management.
* **PA1_Scraper & WebCrawler:** Automated data extraction pipelines to scrape and parse web data efficiently.
* **PA2_Data Pipeline & Integration Using SQL:** Building robust relational databases and executing complex SQL queries for data integration.
* **PA3_Record Linkage:** Implementing techniques to identify and merge duplicate records across different datasets.
* **PA4_Algorithms_Hash Table & Markov Chain in NLP:** Custom implementation of Hash Tables and using Markov Chains for fundamental NLP text generation tasks.

### 2. [Machine_Learning](./Python_Projects/Machine_Learning/)
Advanced analytical projects focusing on ML models and social dynamics.
* **AI Agents Interaction Pattern Analysis:** * **Description:** An in-depth analysis of social dynamics and interaction patterns among AI agents (e.g., simulating environments like the Moltbook forum). This project explores how computational agents form networks and share information.
    * **Files:** Jupyter Notebook (`.ipynb`), Detailed Report (`.pdf`), and Presentation Deck (`.pptx`).

### 3. [Python_Application](./Python_Projects/Python_Application/)
Applied projects utilizing Python data structures, algorithms, and libraries (Pandas, NumPy) to model social phenomena and analyze real-world data.
* **PA1_SocialScience_Epidemic Simulation:** Simulating disease spread using network graphs and probability models.
* **PA2_SocialScience_Modeling Language Shifts:** Modeling how languages evolve and shift within populations over time.
* **PA3_NLP_Election Tweets Analysis:** Analyzing public sentiment and discourse around elections using NLP techniques on Twitter/X data.
* **PA4_DataStructure_Polling Places:** Optimizing and structuring geographic/polling location data using advanced Python data structures.
* **PA5_NumpyPandas_Linear Regression:** Implementing linear regression models from scratch and utilizing Pandas/NumPy for statistical analysis.
* **PA6_Recursion_Avian Biodiversity Treemaps:** Using recursive algorithms to visualize avian biodiversity data hierarchically through treemaps.
